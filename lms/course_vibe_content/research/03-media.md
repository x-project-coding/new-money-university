# Brief: AI-медиа для лендингов (проверено 08.2026)

## Картинки: кто чем силён
GPT Image 2 - ЛУЧШИЙ по плотному тексту в картинке И по кириллице (лидер рейтинга 1370).
Ideogram 4.0 - короткая ударная типографика (постер/вывеска/упаковка), OCR 0.97, дешевле.
Recraft - ЕДИНСТВЕННЫЙ нормальный источник настоящего SVG + прозрачный фон из коробки + бесшовные
паттерны (Seamless Vector/Digital) для background-repeat. Основательница - автор CatBoost, экс-Яндекс.
Midjourney - эстетика, но Discord заблокирован РКН (учить только веб), бесплатного тарифа НЕТ.
Kandinsky 6.0 (Сбер, FusionBrain) - RU без VPN, соглашение ПРЯМО отдаёт права пользователю.
FLUX.2 - текущее поколение (FLUX 3 пока только видео/аудио).

## ЛИЦЕНЗИОННЫЕ ЛОВУШКИ (отдельный слайд)
1. «Бесплатно» != «можно использовать»: Ideogram Free - МОЖНО коммерчески (но генерации публичны);
   Recraft Free - НЕЛЬЗЯ (картинки принадлежат Recraft); Leonardo Free - IP принадлежит Leonardo;
   Freepik Free - AI-выход некоммерческий, а СТОК коммерческий с атрибуцией (новички склеивают);
   GigaChat Freemium - только личное; Шедеврум - коммерция ЗАПРЕЩЕНА (п.3.3/3.5 условий).
2. Лицензия != владение: Midjourney отдаёт владение, но забирает бессрочную сублицензию.
3. ВЫБОР МОДЕЛИ В ВЫПАДАШКЕ МЕНЯЕТ ПРАВО: в Firefly переключение на стороннюю модель обнуляет
   индемнификацию (дословно в условиях).
ADOBE ПОЛНОСТЬЮ ОТКЛЮЧИЛА РОССИЮ 07.07.2026 - вырублены даже оплаченные подписки. Firefly для РФ -
только теория.

## Прозрачный фон / вырезание
Умеют: Recraft (лучший для иконок), gpt-image-1.5/-1/-mini через API, Ideogram (+ Background Remover),
Leonardo Beta, ComfyUI LayerDiffuse (настоящая RGBA, бесплатно).

МИНА: BRIA RMBG-2.0 - CC BY-NC, ТОЛЬКО НЕКОММЕРЧЕСКИ, а его советуют как «бесплатный».

## Спека и LCP
<video autoplay muted loop playsinline poster="hero.avif" preload="none" aria-hidden="true" tabindex="-1">
 <source src="hero.webm" type="video/webm"><source src="hero.mp4" type="video/mp4"></video>
muted ОБЯЗАТЕЛЕН (иначе автоплей запрещён), playsinline обязателен (иначе iOS откроет фулскрин).
LCP-элемент = POSTER (AVIF/WebP 150-250 КБ, fetchpriority=high), НЕ видео. preload="none".
На мобильных видео НЕ отдавать вообще - только постер. prefers-reduced-motion: reduce -> скрыть видео.
ffmpeg: -an -movflags +faststart; H.264 crf 28; VP9 crf 36 (на 30-40% легче). GIF 3.7МБ -> mp4 551КБ
-> webm 341КБ. GIF на лендинге не место.
ЛУП: один кадр отдать И первым И последним + описывать только циклическое движение. Подстраховка -
xfade хвоста в начало через ffmpeg.

## Промпты (6 шт RU+EN в полном брифе)
Словарь: slow subtle drift, gentle parallax, barely perceptible motion, locked-off camera, seamless
loop first and last frame identical, no cuts single continuous shot, generous negative space on the
left for text overlay.
ГЛАВНЫЙ РЕЦЕПТ: сгенерировать идеальный КАДР картиночной моделью (дёшево, контроль) -> оживить через
image-to-video «минимальным движением: параллакс фона, мерцание света, объект неподвижен».
НЕ пытаться заставить модель нарисовать реальный интерфейс - будет каша вместо букв.

## ВСТРАИВАНИЕ - главное решение для РФ
YouTube в РФ: замедление с середины 2024, по данным источника - полная блокировка 12.02.2026
(ПОМЕТИТЬ КАК ПРОВЕРЯЕМОЕ, тема чувствительная). Практический вывод: YouTube-эмбед для российской
аудитории = чёрный прямоугольник у большинства.
Лестница: луп <=3 МБ -> САМОХОСТ + CDN (дефолт, без блокировок и куки-баннеров). Демо 30-90с для РФ ->
Kinescope (free 100 мин + 200 ГБ, Super от 10 евро) или VK Video / Rutube (бесплатно). Международная
аудитория -> Cloudflare Stream ($5 за 1000 мин хранения + $1 за 1000 мин просмотра) или Bunny.
Если YouTube всё же нужен - lite-youtube facade (в 224 раза быстрее обычного iframe).
НЕ ХОСТИТЬ видео на Vercel: Hobby 100 ГБ трафика, один удачный день съест квоту.
Rutube эмбед: <iframe src="https://rutube.ru/play/embed/ID" allow="clipboard-write; autoplay">

## Лицензионные ловушки видео

вотермарка + без коммерции; Hailuo free - только личное. Кредиты не переносятся, НЕУДАЧНЫЕ ГЕНЕРАЦИИ
НЕ ВОЗВРАЩАЮТСЯ (закладывать ~2 попытки на клип). SynthID у Veo неотключаем. Агрегатор = разрыв в
цепочке прав (подписчик - перепродавец, не вы). Открытые веса (Wan 2.7 Apache-2.0) - единственный
полностью чистый путь.
