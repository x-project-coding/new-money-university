# Brief: домены и хостинг в РФ (проверено 10.08.2026)

## Домены
Reg.ru .ru = 169 руб первый год, 226 продление (ловушка продления - всегда смотреть ВТОРОЙ год).
!!! С 01.09.2026 администраторы .ru/.рф/.su проходят идентификацию через Госуслуги. Домены,
ОПЛАЧЕННЫЕ И НАСТРОЕННЫЕ ДО 1 сентября, работают весь оплаченный срок без идентификации. .com не
затронут. -> практический совет студенту: если берёшь домен - бери и настраивай DNS сразу.
Домен В ПОДАРОК: Timeweb даёт 3 домена .RU/.РФ на любом тарифе хостинга; SpaceWeb - 1 домен при
годовой оплате; Selectel - домен .RU/.РФ при заказе VPS (акция до 30.09.2026).
ГЛАВНОЕ ПРАВИЛО: домен регистрируется НА ИМЯ КЛИЕНТА и в ЕГО аккаунт (ICANN: 60-дневная блокировка
трансфера; узнать в день запуска, что домен в чужом аккаунте = минус 60 дней).

## Бесплатно разместить статику внутри РФ

2) Yandex Object Storage free tier: 1 ГБ хранения + 100 000 GET + 100 ГБ ИСХОДЯЩЕГО ТРАФИКА в месяц

нарушение локализации ч.5 ст.18 152-ФЗ. (Для сайта-визитки БЕЗ формы - можно.)

# ДОПОЛНЕНИЕ (финальный бриф, 10.08.2026) - критичные поправки
1. ПРОДЛЕНИЕ ДОМЕНА .ru: разброс по рынку ПОЧТИ В 10 РАЗ - SpaceWeb 319, Timeweb 399, Beget 420,
   Руцентр 3075. Reg.ru цену продления НЕ ПУБЛИКУЕТ до входа в ЛК. Модные зоны: .store 140 -> 6767,
   .online 125 -> 4401. Правило: смотреть цену ВТОРОГО года.
2. CLOUDFLARE В РФ ФАКТИЧЕСКИ НЕ РАБОТАЕТ с 09.06.2025 - троттлинг после ~16 КБ (официально признано
   Cloudflare). Если уже используется - переводить в «серое облако» (DNS only). Замены: Beget CDN,
   Yandex Cloud CDN, Selectel CDN.
3. VERCEL HOBBY ЗАПРЕЩАЕТ КОММЕРЧЕСКОЕ ИСПОЛЬЗОВАНИЕ дословно («non-commercial personal use only»),
   включая рекламу товара, партнёрские ссылки и донаты. GitHub Pages - тоже запрет коммерции.
   Netlify перешёл на кредиты (300 кредитов ~15 ГБ), Netlify сами пишут: блокируют IP, а не домен -
   «ищите провайдера, который не заблокирован».
4. СВОЙ .ru ДОМЕН НЕ ЧИНИТ ДОСТУПНОСТЬ - блокировка на уровне IP.
5. НОВОЕ: ст. 13.55 КоАП с 07.07.2026 - ИНОСТРАННАЯ АВТОРИЗАЦИЯ ЗАПРЕЩЕНА («Войти через Google/Apple/
   Facebook»): юрлица 500-700 тыс. Разрешено: телефон+SMS, ЕСИА, VK ID, Яндекс ID, Сбер ID. Проверять
   и виджеты (Disqus, Intercom, Tilda Members). Если авторизации нет вообще - норма не применяется.
6. НОВОЕ: КоАП 14.7 ч.2 - ВВЕДЕНИЕ В ЗАБЛУЖДЕНИЕ 100-500 тыс: гарантия дохода, фейковые отзывы,
   выдуманные цифры, ФИКТИВНЫЕ ТАЙМЕРЫ «осталось 3 места», зачёркнутые несуществующие цены.
   !!! Это прямо противоречит стандартному RU-совету «поставь таймер» - таймер должен быть НАСТОЯЩИМ.
7. РЕКВИЗИТЫ В ФУТЕРЕ обязательны (ПП 2463 п.19, с 01.09.2026 - ПП 657 п.22): ЮЛ - наименование, ОГРН,
   адрес, e-mail/телефон; ИП - ФИО, ОГРНИП, e-mail/телефон. Штраф КоАП 14.5 ч.1: 30-40 тыс.
8. «НЕ ЯВЛЯЕТСЯ ПУБЛИЧНОЙ ОФЕРТОЙ» НЕ РАБОТАЕТ для ТОВАРОВ (ГК ст.494 п.2: сведения о товарах в
   интернете = публичная оферта независимо от указания цены). Для УСЛУГ - работает.
   ЗоЗПП ст.32: отказ от услуги В ЛЮБОЕ ВРЕМЯ с оплатой фактических расходов; «возврата нет» ничтожно.
9. ЭКВАЙРИНГ: с 01.01.2026 НДС 22% на комиссию -> заявленные 2.8% фактически ~3.42%. СБП И T-Pay НДС
   НЕ ОБЛАГАЮТСЯ. СБП: потолок ЦБ 0.7%, МАКСИМУМ 1500 руб ЗА ОПЕРАЦИЮ -> на чеке 100 тыс карта даёт
   ~2800 руб комиссии, СБП максимум 1500. Прямое подключение через банк дешевле агрегатора.
   ЮKassa самозанятым 3.5%, лимит 500 тыс/мес. Физлицу без статуса легального способа НЕТ.
   Самозанятый: 4%/6%, лимит 2.4 млн/год, ЧЕК В МОМЕНТ РАСЧЁТА, штраф 20% (повторно 100%).
   НЕЛЬЗЯ: перепродажа чужих товаров, агентские/комиссия, наём, доходы от работодателя < 2 лет назад.
10. МЕТРИКА: ЗАПРЕЩЕНО передавать ПДн (ФИО/телефон/почта). Маскировать: class="ym-disable-keys" на
    поля, class="ym-hide-content" на блоки. Цель ставить через reachGoal ПОСЛЕ успешного ответа
    сервера (готовая цель «отправка формы» ломается на div-формах). Есть опция «не сохранять полные IP».
11. robots.txt: директивы Host и Crawl-delay МЕРТВЫ (с 2018). Нужен Clean-param для utm/yclid.
    Турбо-страницы Яндекса ЗАКРЫТЫ 07.04.2025. Доля поиска РФ: Яндекс 72.85%, Google 25.48%.
12. Let's Encrypt для .ru РАБОТАЕТ (ограничение только для госучреждений и подсанкционных лиц).
    Российский НУЦ не годится: корневой сертификат только в Яндекс.Браузере и Атоме.
13. nginx: с 1.25.1 синтаксис «listen 443 ssl; http2 on;» (старое «listen 443 ssl http2» устарело).
    gzip по умолчанию сжимает ТОЛЬКО text/html - без gzip_types CSS и JS остаются несжатыми.
14. Шрифты: crossorigin в preload ОБЯЗАТЕЛЕН даже для своего домена (иначе шрифт качается дважды).
    «№» = U+2116 и ударение U+0301 живут в кириллическом сабсете.
15. Aeza под санкциями OFAC (01.07.2025) - не рекомендовать. Beget под санкциями ЕС (латвийская
    локация закрыта 23.07.2026, российская работает).
16. Смена NS у работающего домена - 24-72 часа (регистрация нового домена - 2-6 часов). За сутки до
    переезда снизить TTL до 300-600.
17. WHOIS физлица скрыт БЕСПЛАТНО по умолчанию (только «PRIVATE PERSON») - аргумент регистрировать
    на физлицо. У юрлица наименование и ИНН публичны всегда.
18. Yandex Object Storage free: 1 ГБ + 100 000 GET + 100 ГБ трафика в месяц - лендинг за 0 руб/мес.
19. Timeweb Cloud Apps от 1 руб/мес - деплой из GitHub, free SSL + домен: ближайший отечественный
    аналог Vercel.
