## Benchmarks (teach the discrepancy!)
Ruler 05.2026 (110M сессий): средняя конверсия 5.13%; авто/юр 7.9%, софт 7.6%, образование 6.3%,
красота 3.5%, недвижимость 2.8%, e-com 2.4%. По источникам: ИИ-реферал 5.8% > платный поиск 5.4% >
email 4.9% > соцсети 2.1-2.2%.
Unbounce (41k лендингов): медиана 6.6%; email 19.3%, Instagram 17.9%, платный поиск 10.9%.
МОБИЛЬНЫЙ = 83% трафика и конвертит на ~8% ХУЖЕ. Текст на уровне 5-7 класса конвертит 11.1% против
5.3% у «профессиональной» прозы; слова 3+ слогов -24.3%.
ПРАВИЛО: никогда не обещай клиенту число из чужой таблицы - меряй его базу и продавай дельту.

## Скорость = деньги
Portent: e-com 3.05% @1с -> 1.68% @2с -> 1.12% @3с. B2B лидоген 40% @1с -> 29% @3с.
Сайт за 1 секунду конвертит в 3 раза лучше, чем за 5 секунд.
Core Web Vitals: LCP <=2.5s, INP <=200ms, CLS <=0.1 (p75, мобайл отдельно).

## Внимание и форма
NN/g: 57% времени - выше первого экрана; топ 20% страницы = 42% внимания.
Baymard: среднее 11.3 поля, нужно 8; 17% бросают из-за сложности. Сокращать ВИДИМЫЕ поля важнее,
чем число шагов. Лендинг-лидоген = 3 поля (имя, телефон/email, один квалификатор).

## Структура (канон) + что в блоке
hero (один outcome-заголовок + подзаголовок + ОДИН CTA + токен доверия + реальный скрин продукта) ->
проблема (словами читателя; Basecamp: «Tell me if this sounds about right») -> решение (3 шага, у
каждого свой визуал ПРОДУКТА) -> пруф (число с источником: GetCourse «70% онлайн-школ России») ->
оффер (цена/вилка!) -> FAQ (5 реальных возражений) -> финальный CTA (та же формулировка + снятие
риска). ВАЖНО: FAQ-schema больше НЕ даёт rich results (только гос/мед сайты) - FAQ ради конверсии.

## RU-специфика структуры (НЕ «чинить», а знать)
RU-лендинги в 2-4 раза длиннее. Обязательны: «О компании», «Наши преимущества», «Этапы работы»,
«Сертификаты», «Факты в цифрах», виджет обратного звонка, таймер, квиз. CTA повторяется 3+ раза.
Envybox (живой): hero -> преимущества -> продукты -> интеграции -> ОТЗЫВЫ -> КЕЙСЫ (пруф в конце,
наоборот от Запада).
Квизы: конверсия в ЛИД выше (8-20% vs 3-8%), но в ПРОДАЖУ ниже (3-10% vs 10-25%). Инструмент CPL,
не выручки.
4U «+50-80% конверсии» = ФОЛЬКЛОР (один источник без исследования). Кот учит ~8 слов в заголовке,
4U даёт 12-18 - показать конфликт честно. Ильяхов: промостраница = демонстрации, не формулы.

## Чек-лист сдачи
Мобайл: 360/390/414/768/1280/1920 на РЕАЛЬНОМ телефоне; ноль горизонтального скролла; тач-цели >=24px
(лучше 48); инпуты >=16px (иначе iOS зумит); 100dvh вместо 100vh.
Скорость: LCP<=2.5 INP<=200 CLS<=0.1; PageSpeed мобайл >=85; WebP/AVIF + width/height + lazy кроме
hero; шрифты swap + сабсет кириллицы <=2 начертания.
Формы: тест-отправка С ТЕЛЕФОНА на мобильном интернете + подтверждение, что клиент получил; понятный
success; honeypot -> Turnstile -> reCAPTCHA (последней); доставка email + TG-бот; SPF/DKIM/DMARC.
Аналитика: Метрика + вебвизор + ЦЕЛИ настроены (счётчик без целей бесполезен); проверить события в
реалтайме; UTM доезжают до заявки скрытыми полями.
Мета: title 50-60, description 150-160, OG + og:image 1200x630, проверить превью вставкой в телеграм;
фавикон-набор (favicon.ico 32, icon.svg, apple-touch-icon 180, 192, 512, maskable, manifest);
lang="ru", canonical, robots.txt, sitemap.xml.
Инфра: HTTPS без mixed content, 301 www, живая 404, домен +12 мес с автопродлением, бэкап файлом.
ПЕРЕДАЧА (где фрилансеры убивают репутацию): домен НА ИМЯ КЛИЕНТА и его аккаунт (мистейк №1);
хостинг на клиента; счётчик Метрики создавать В АККАУНТЕ КЛИЕНТА и дать себе доступ (не наоборот);
Тильда - передать проект и ПИСЬМЕННО предупредить про абонплату и экспорт только на Business-годовом;
код - передать репозиторий + zip сборки + исходники; пароли одноразовой ссылкой; 5-минутный
скринкаст «как править текст, где заявки, как смотреть Метрику» (даёт больше повторных заказов, чем
портфолио); письменный чек-лист сдачи; права на портфолио - письменно ДО старта.
